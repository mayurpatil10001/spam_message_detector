How SpamShield works

A beginner-friendly web application that combines Natural Language Processing (NLP) and supervised machine learning to classify text messages.

Processing pipeline

01Input

User enters message text.

→
02TF-IDF

Text becomes numeric features.

→
03Classifier

Logistic Regression predicts a label.

→
04Result

Show class and confidence.

Technology stack

  • Python — core programming language
  • Flask — web framework and routing
  • scikit-learn — TF-IDF and Logistic Regression
  • HTML/CSS/JavaScript — user interface and character counter
  • joblib — save and load the trained pipeline
Dataset limitation: This starter version uses a small built-in example dataset so it works immediately. Its confidence score is not a calibrated measure of real-world reliability. For a stronger academic evaluation, train and test on a larger labeled SMS dataset using a held-out test split.
